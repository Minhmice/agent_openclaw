# Page Checklist Template

Copy this template once per page.

## Page identity

- [ ] Project and page slug recorded.
- [ ] Page role in funnel recorded.
- [ ] Primary audience recorded.
- [ ] Primary conversion action recorded.
- [ ] Success metric recorded.
- [ ] Owner assigned.
- [ ] Target day assigned.

## Strategy and message

- [ ] Headline drafted.
- [ ] Supporting promise drafted.
- [ ] Three proof points identified.
- [ ] Primary CTA written.
- [ ] Objections/FAQ listed.
- [ ] Tone matches the selected design genome.

## Evidence and content

- [ ] Business facts linked to source URLs.
- [ ] Inferences labeled.
- [ ] Estimates labeled.
- [ ] Product/service scope complete.
- [ ] Benefits and use cases complete.
- [ ] Proof/testimonial/certificate/client evidence complete.
- [ ] Images/video/assets identified and assigned.
- [ ] Contact/quote/booking content complete.
- [ ] Legal/privacy content checked when applicable.

## Page structure

- [ ] Section order approved.
- [ ] Every section has a purpose.
- [ ] Content hierarchy is explicit.
- [ ] CTA appears at the right decision points.
- [ ] Internal links defined.
- [ ] Empty/error/success states considered.

## SEO

- [ ] URL/slug decided.
- [ ] Title tag written.
- [ ] Meta description written.
- [ ] Exactly one H1.
- [ ] H2/H3 hierarchy checked.
- [ ] Image alt text prepared.
- [ ] Canonical/indexing decision recorded.
- [ ] Schema opportunity recorded.

## Design and responsive

- [ ] Layout family matches the design genome.
- [ ] Typography tokens used.
- [ ] Color roles use tokens.
- [ ] Shape/radius language is consistent.
- [ ] Image art direction is followed.
- [ ] Signature element is used deliberately.
- [ ] Desktop behavior checked.
- [ ] Tablet behavior checked.
- [ ] Mobile behavior checked.
- [ ] Motion follows motion grammar.
- [ ] Reduced-motion behavior exists.

## QA and approval

- [ ] CTA/link/form works.
- [ ] Mobile tap targets are usable.
- [ ] Focus states are visible.
- [ ] Contrast/readability checked.
- [ ] No placeholder copy remains.
- [ ] No unsupported claim remains.
- [ ] No P0/P1 issue remains.
- [ ] Page owner confirms done.
- [ ] Stakeholder confirms approved.
- [ ] Screenshot/evidence is attached.

## Status

```text
planned → content-draft → content-ready → design-ready
→ qa-needed → stakeholder-review → approved
```

```yaml
status:
blocked_reason:
last_update:
next_action:

```
