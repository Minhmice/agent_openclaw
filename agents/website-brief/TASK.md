# Website Brief Agent Task

## Primary workflow

```text
approved lead
  → discover pages
  → crawl text/CSS/assets/metadata
  → capture desktop/tablet/mobile screenshots
  → extract product/business truth
  → build content inventory
  → extract brand and visual DNA
  → analyze sections semantically
  → diagnose KEEP/EVOLVE/RETIRE
  → analyze category/competitors
  → select PRESERVE/REFRESH/EVOLVE/OVERHAUL
  → write design thesis
  → generate 5–7 visual worlds
  → score and select one north star
  → generate genome/tokens/components/page blueprints
  → critique homepage direction
  → freeze DESIGN.md and JSON package
```

## Page-level output requirements

For each major page blueprint define:

- Page goal.
- Primary user.
- Primary conversion.
- Message sequence.
- Section order.
- Section purpose.
- Content source/evidence.
- Layout family.
- Visual emphasis.
- CTA.
- Proof.
- Component.
- Image direction.
- Responsive behavior.
- Open questions.

Use the shared Curie page playbook for “executive surprise” packaging: personalized opening, before/after contrast, transparent opportunity hypothesis, three quick wins, and one low-friction next step.

## Definition of done

The package is ready for PM scheduling only when:

- Business identity and audience are understandable.
- Primary conversion path is explicit.
- Brand invariants and anti-references are documented.
- Design mode, thesis, north star, genome, tokens, components, and page blueprints exist.
- Responsive/accessibility/motion rules exist.
- Homepage direction has passed critique.
- Every major visual decision traces back to the design genome.
- Unresolved questions and confidence gaps are listed.
